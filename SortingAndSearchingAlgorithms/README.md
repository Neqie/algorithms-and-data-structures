# Sorting and Searching Algorithms

Учебный проект на языке C, демонстрирующий реализацию классических алгоритмов сортировки и поиска в массиве.  

Программа представляет собой консольное приложение с интерактивным меню. Основная цель - реализовать и сравнить эффективности алгоритмов по количесвту операций и затраченному времени.

## Реализованный функционал

### Алгоритмы сортировки
**Линейная сортировка** - `long long linesort(int arr[], int n)`, возвращает количество операций, совершенных при вызове функции, arr - массив, передаваемый для сортировки, n - количуство элементов массива.  
**Пузырьковая сортировка** - `long long bubblesort(int arr[], int n)`, аналогично линейной сортировке.  
**Сортировка вставкой** - `long long insertionsort(int arr[], int n)`, аналогично.  

### Алгоритмы поиска
**Линейный поиск** - `int line_search(int arr[], int n, int ch)`, возвращает индекс числа в массиве, arr - массив, в которо ищем число, n - количество элементов, передаваемого массива, ch - число, которое необходимо найти.  
**Поиск барьером** - `int sentinel_search(int arr[], int n, int ch)`, аналогочно линейному поиску.  
**Бинарный поиск** - `int bin_search(int arr[], int n, int ch)`, аналогично линейному поиску.  

### Дополнительно
* Интерактивное меню с выбором действия.  
* При вводе большого количества элементов в массиве (от 21 до 90000), он заполняется случайными числами.  
* Подсчет `времени` работы сортировок

## Сборка и запуск

Необходимо:

* Компилятор C/C++ (МVisual Studio C++/GCC/Clang)
* CMake 3.10 и выше

### Сборка через консоль
Выполните следующие действия в папке с файлом CMakeLists.txt:
```bash
mkdir build
cd build
cmake ..
cmake --build .
```
