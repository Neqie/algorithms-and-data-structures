# Algorithms and Data Structures

Репозиторий содержит реализации ключевых алгоритмов и структур данных на языке C++, выполненные в рамках учебного процесса и самостоятельной практики.

Проект организован по принципу модульной структуры: каждый раздел помещен в отдельную директорию со своим собственным `README.md` файлом, содержащим документацию.  

---

## Содержание репозитория

| № | Тема | Описание | Ссылка на исходный код |
|---|---|---|---|
| **1** | **TString** | Пользовательский класс динамической строки с поддержкой управления памятью и перегрузкой операторов | [Перейти к TString](./TString) |
| **2** | **Sorting and Searching algorithms** | Учебная программа по работе с алгоритмами сортировок и поиска в массиве | [Перейти к SortingAndSearchingAlgorithms](./SortingAndSearchingAlgorithms) |
|

## Технологии и требования

- **Язык программирования:** C++ 17 / C++ 20
- **Среда разработки:** Visual Studio 2022
- **Система сборки:** MSBuild / C++ Compiler (`cl.exe`)

---

## Навигация и запуск

1. Перейдите в папку интересующего вас проекта.
2. В каждом каталоге находится локальный `README.md` с инструкцией по сборке.
